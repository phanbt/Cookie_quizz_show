# Cookie Quiz Show

A whole-class multiple-choice quiz game for the classroom.

**Play it:** https://phanbt.github.io/Cookie_quizz_show/

## How it works

1. The gamemaster enters how many questions to play, then types each question and its correct answer.
2. Each question needs three wrong answers. Type them yourself, or click **Fill the wrong answers**: numbers get nearby numbers, and other answers are borrowed from your other questions.
3. Click **Start the game** and put it on the big screen.
4. Students choose A, B, C or D. A wrong choice is greyed out and crossed so another student can try. After 2 wrong answers the correct one lights up and the game moves to the next question by itself after 5 seconds.
5. When a student picks the right answer, type their name (or tap it) to give them a cookie. Names that already have cookies just get one more.
6. At the end, the student with the most cookies is the champion (ties are shown too).

- **Start over** plays the same questions again with everyone back to zero.
- **New questions** goes back to setup to write a new set.

Questions are saved in your browser, so they are still there after a reload.

The whole game is a single file, `index.html`, with no build step.
